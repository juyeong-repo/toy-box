# Fullstack Engineer 과제: 칸반 보드

## 필수 요구 사항
- 사용자가 회원 가입, 로그인, 로그아웃을 할 수 있습니다.
- 사용자 인증은 JWT로 해야 합니다.
- 일감의 속성은 제목, 생성자, 상태로 구성되며 일감을 생성, 수정, 삭제할 수 있습니다.
  - 생성자는 로그인한 사람입니다.
- 일감의 상태는 드래그앤드랍으로 변경할 수 있습니다.
  - 일감의 상태가 변경되면 다른 사용자에서 화면도 갱신이 되어야 합니다.
  - 여러 사용자가 동시에 한 일감을 수정했을 때 발생할 수 있는 동시성 문제를 정의하고 해결해야 합니다.
- [Figma](https://www.figma.com/design/cx90GFbInHZ8KTFkR7aLIi/%EA%B0%9C%EB%B0%9C-%EC%B1%84%EC%9A%A9-%EA%B3%BC%EC%A0%9C-%ED%99%94%EB%A9%B4--%EC%99%B8%EB%B6%80%EA%B3%B5%EC%9C%A0%EC%9A%A9-?node-id=21-1078&t=MelZAtz7OeB5kJfC-1)와 동일하게 구현되어야 합니다.
- 과제는 `docker compose up`으로 실행되어야 합니다.

## 선택 요구 사항
- 검색 기능이 구현되면 좋습니다.
  - 일감의 제목 또는 생성자를 기준으로 검색이 되어야 합니다.
  - 검색할 내용을 입력하는 과정에서 검색어가 포함된 일감이 칸반 보드에 보여야 합니다.
- 프론트엔드의 테스트 코드를 작성해주시면 좋습니다.
- 백엔드의 테스트 코드를 작성해주시면 좋습니다.

## 제출 규칙
- 과제 발송일로부터 **7일** 이내에 제출해야 합니다.
  - 시간이 더 필요하다면 RoundHR을 통해 연락해 주시면 됩니다.
- 과제는 Pull Request를 통해 제출해야 합니다.
  - 과제 평가는 코드 리뷰를 통해 진행됩니다.
- API 문서도 제출해야 합니다.
- 데이터 모델 설계 도면과 설명도 제출해야 합니다.
- AI로 코드를 작성한 경우에 어떤 부분을 AI가 작성했는지 명시해 주세요.
